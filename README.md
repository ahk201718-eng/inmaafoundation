# مواد الرفع — HRMS · نسخة **hrms2**

هذا المجلد يحتوي **كل ما ترفعه**، مقسومًا إلى مهمّتين لا تختلطان.
**لا أوامر، ولا `npm install`، ولا بناء.**

---

## ١ · الموقع (Vercel) — الملفات في هذا المجلد نفسه

٤٨ ملفًا، **بلا أي مجلد فرعي** — لذلك `Ctrl+A` داخل المجلد ثم سحبها يعمل دائمًا.

### الخطوات

1. GitHub ← مستودع جديد (أو المستودع الحالي بعد حذف ملفاته القديمة).
2. **Add file → Upload files**.
3. افتح هذا المجلد، اضغط `Ctrl+A`، اسحب كل الملفات إلى الصفحة، ثم **Commit**.
4. Vercel ← **Add New → Project** ← اختر المستودع ← **Deploy**.
   لا تكتب Build Command ولا Output Directory.

النتيجة:

```
https://<المشروع>.vercel.app/         لوحة اختيار الواجهة
https://<المشروع>.vercel.app/admin    لوحة مسؤول النظام
https://<المشروع>.vercel.app/mobile   تطبيق الموظف
```

> **لا ترفع `package.json`** إلى هذا المستودع. وجوده وحده يجعل Vercel يحاول
> البناء ويفشل — وهذا أصل كل تعطّل سابق. هذا المجلد لا يحتويه.

### الدخول

```
admin / admin
```

غيّرها من شاشة «المستخدمين» فور أول دخول.

## ٢ · الخادم (اختياري) — ملف واحد إلى صفحة Releases

تحديث الخادم لا يمرّ بالمستودع، بل بملف إصدار:

| | |
|---|---|
| الملف | `../hrms2-server.tar.gz` (١٫٣٧MB، بجوار هذا المجلد) |
| مكانه | المستودع ← **Releases** ← *Draft a new release* ← Tag `v1.1` ← أرفق الملف ← **Publish** |
| بعدها | على الخادم: `sudo bash update.sh` |

التفاصيل في `hrms2/deploy/README-UPDATE.md`.

> إن لم يكن لديك خادم بعد، تجاهل هذا القسم بالكامل — القسم الأول وحده يكفي
> لتشغيل الموقع.

## ما في هذا المجلد

| | |
|---|---|
| `index.html` | لوحة اختيار الواجهة |
| `admin.html` · `desktop.html` · `mobile.html` | الواجهات الثلاث |
| `AppRoot-*.js` · `*.css` · `*.wasm` | التطبيق وقاعدة البيانات |
| `*.ttf` | الخطوط |
| `sw.js` · `manifest.webmanifest` | العمل بلا شبكة وتثبيت التطبيق |
| `vercel.json` | مسارات مختصرة: `/admin` بدل `/admin.html` |

## ملاحظتان

**بعد كل نشر جديد**: اضغط `Ctrl+F5` مرة — عامل الخدمة (`sw.js`) قد يخدم نسخة
قديمة من الشاشة حتى يُحدَّث.

**حدود هذه النسخة**: قاعدة SQLite داخل المتصفح — مستخدم واحد، جهاز واحد، ولا
مزامنة بين الأجهزة. لعدة موظفين: نسخة الخادم (`hrms1`).
